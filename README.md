 # Creative Work Single Page Application (SPA)

A modern, responsive React single-page portfolio showcase built for a creative agency. This web platform allows agency members to showcase past work and dynamically append new projects.

## Features
- **Project Showcase Landing Page:** Renders interactive project cards.
- **Dynamic Form Submission:** Allows users to add projects with custom names, descriptions, phases, image URLs, and external links.
- **Real-time Search Filter:** Instantly filters projects dynamically by matching titles or text content.
- **Fully Responsive Layout:** Optimized grid layout adaptable across mobile, tablet, and desktop screens.
